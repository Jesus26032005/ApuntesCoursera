La estructura de un proyecto React es fundamental para organizar los componentes y facilitar el desarrollo y mantenimiento de la aplicación.

Estructura de carpetas principales

node_modules: Contiene todos los módulos y paquetes instalados mediante npm, necesarios para que la app funcione.
public: Almacena los recursos visibles para el usuario, como imágenes, favicon, archivo robots.txt y el archivo index.html donde se inyecta la app React.
Carpeta src (source)

Contiene los archivos esenciales para que la app funcione, incluyendo componentes React, estilos CSS y archivos de prueba.
Archivos importantes: index.js (punto de entrada que importa todo lo necesario para renderizar la app) y app.js (componente raíz).
Archivos en la raíz del proyecto

.gitignore: Define qué archivos o carpetas se excluyen del control de versiones.
package.json y package-lock.json: Gestionan las dependencias y scripts npm para construir y mantener la app.
README.md: Documento con información básica del proyecto para compartirlo, por ejemplo, en GitHub.
Esta estructura predeterminada puede personalizarse para organizar mejor componentes y recursos, lo que facilita el desarrollo escalable y mantenible.

Análisis de la sintaxis

¿Por qué utilizar el atributo className en la sintaxis JSX?

Bueno, con JSX, se parece tanto a HTML que es fácil olvidar que en realidad es código JavaScript, no HTML.

Mientras que el HTML normal sí tiene un atributo class, que se utiliza para listar una o más clases CSS que se utilizarán en un elemento HTML dado, esto no puede funcionar realmente en JSX. La razón es que JSX es un tipo especial de sintaxis JavaScript, y la palabra class es una palabra clave reservada en JSX. Por eso el equipo de React tuvo que llegar a un compromiso y así className se usa en JSX para listar una o más clases CSS a usar en un elemento o componente dado.

Pero, ¿por qué usar Intro1.js, Intro2.js e Intro3.js? ¿No es uno de los principios de la codificación el enfoque DRY, es decir, el enfoque "No te repitas"?

Así es. Sin embargo, todavía hay que discutir algunos conceptos antes de aprender a reutilizar un mismo componente con variaciones en su contenido. Esto tiene que ver con los datos en los componentes, pero no te preocupes, llegaremos a eso más adelante.
