Los hooks también vienen con un conjunto de reglas que necesitas seguir mientras los usas. Esto se aplica a todos los hooks de React, incluyendo el hook useState que acabas de aprender.

Sólo puedes llamar hooks en el nivel superior de tu componente o tus propios hooks.

No puedes llamar hooks dentro de bucles o condiciones.

Sólo puedes llamar hooks desde funciones React, y no desde funciones JavaScript normales.

"Levantar estado" (Lifting State Up)

Sí, se puede y de hecho es uno de los patrones más comunes en React. Vamos a explicarlo desde cero.

El problema que resuelve

Imagina que tienes dos componentes hermanos (al mismo nivel, ninguno es padre del otro) y necesitan compartir información o mantenerse sincronizados.

javascript
function App() {
  return (
    <div>
      <Termometro />   {/* tiene su propia temperatura */}
      <Grafica />      {/* necesita esa misma temperatura para dibujar algo */}
    </div>
  );
}

Si Termometro guarda su temperatura con su propio useState, Grafica no tiene forma de acceder a ese valor. Son hermanos, no hay comunicación directa entre componentes hermanos en React — los datos solo fluyen de padre a hijo (hacia abajo).

La solución: "levantar" el estado

Levantar estado significa mover el useState desde el componente hijo hacia el componente padre común más cercano, y luego pasar ese estado hacia abajo como props a los hijos que lo necesiten.

Antes (estado "atrapado" en el hijo):
javascript
function Termometro() {
  const [temp, setTemp] = useState(20); // ❌ atrapado aquí, nadie más lo ve

  return (
    <input value={temp} onChange={(e) => setTemp(e.target.value)} />
  );
}
