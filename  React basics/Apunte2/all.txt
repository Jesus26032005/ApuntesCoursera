​A esta altura, debería estar familiarizado con ​el concepto de componentes funcionales en React. ​Son bloques de código reutilizables que ​actúan como una función JavaScript. ​Recuerda que en JavaScript, ​puede hacer que sus funciones sean más ​flexibles declarándolas con parámetros ​que permiten pasar en valores como argumentos ​cuando llame a la función. ​Bueno, en React, puede realizar ​una acción similar usando algo llamado propiedades, ​que se representan como accesorios. ​En este vídeo, aprenderá sobre el objeto props ​y cómo los desarrolladores los utilizan para pasar ​datos de un componente a otro. ​A continuación, explorará la jerarquía de componentes ​y aprenderá por qué se fijan los componentes ​para tener una estructura padre-hijo. ​Antes de comenzar tu viaje con accesorios, ​vamos a revisar otra funcionalidad JavaScript ​que te ayudarán a entender cómo funcionan los puntales. 
​Se llama objeto JavaScript. ​Recuerda que en JavaScript, ​un objeto es un tipo especial de ​que puede contener muchos valores. ​Los objetos se utilizan cuando se necesita almacenar ​grupos de datos relacionados de diferentes tipos. ​Cada tipo de datos se denomina ​una propiedad de objeto, por ejemplo, ​supongamos que creas un objeto llamado frutas que ​contiene propiedades para tipo, cantidad y color. ​Recuerde que estas propiedades ​consisten en pares nombre-valor, ​y puede acceder a ​las propiedades del objeto usando notación de puntos. ​En React puede usar ​una técnica similar para pasar datos ​de un componente a otro utilizando ​el objeto de propiedades o simplemente accesorios. ​Los accesorios le permiten pasar datos ​de un componente a otro. 
​Es útil pensar en accesorios ​como argumentos que un componente puede aceptar ​y que se traspasan utilizando la sintaxis JSX, ​como los atributos HTML. ​Dentro de la función, se utilizan los accesorios de palabra clave. ​Ahora que está más familiarizado con el concepto de persona-tiempo, ​exploremos un ejemplo para enviar algunos accesorios ​a un componente e imprimirlos en una aplicación React. ​Supongamos que tiene el código por defecto para la aplicación React ​abierta en el archivo index.js, ​llama al componente de la aplicación. ​En el componente de la aplicación, ​devuelve un encabezado h1 con un texto de título estático. ​Mientras este código funciona, ​puede hacer que este encabezado sea dinámico utilizando accesorios. ​Veamos ahora la sintaxis incluida para crear esto.

​Mientras explora el ejemplo básico ​para imprimir dinámicamente un encabezamiento, ​tendrá la oportunidad de practicar con ​estructuras de datos más complejas utilizando accesorios más adelante. ​Ahora está familiarizado con cómo funcionan los accesorios ​enviando datos entre componentes. ​Exploremos este flujo de datos en mayor detalle. ​Cuando dos componentes se comunican entre sí, ​el componente que envía a los datos de accesorios ​se conoce como padre, ​y el componente que recibe ​los datos de accesorios se conocen como hijo. ​Como acaba de aprender con el ejemplo anterior, ​esta relación padre-hijo permite que ​los componentes principales de los datos anteriores ​bajen los componentes hijos usando accesorios. ​También es posible que los componentes padre ​envén los mismos datos a múltiples componentes hijos. ​Sin embargo, es importante saber que ​esta comunicación es un flujo de datos unidireccional.

Para hacer coincidir los ejemplos mostrados a continuación en el REPL de Babel, añada la siguiente línea en la parte superior del ejemplo antes de transpilar: /** @jsxRuntime classic */

Si todavía ve la salida usando react/jsx-runtime, eso también es salida moderna válida siguiendo el tiempo de ejecución automático .

En la salida clásica mostrada arriba, createElement recibe tres argumentos:  

El tipo de elemento a mostrar, como "h1". 

El objeto props, o null si no se han pasado props. 

El contenido hijo que va dentro del elemento.

Curiosamente, el contenido interior que irá dentro del elemento envolvente también puede ser una llamada a la función createElement .

Así que ahora el tercer argumento de la llamada React.createElement más externa es otra llamada React.createElement.

Así es como puedes anidar tantos elementos como quieras.

Esto significa que una estructura JSX anidada es sólo un montón de llamadas React.createElement anidadas, pasadas a otras llamadas React.createElement como su tercer argumento.

El segundo argumento: props
En React.createElement(type, props, ...children), el segundo argumento es el objeto props.

En los ejemplos anteriores, ese valor era null porque no se pasaban props a esos elementos. React trata null igual que un objeto props vacío.

Por ejemplo, si escribieras este JSX:

1234

  return <h1 className="title">Hello there</h1>;
}

function App() {
  return /*#__PURE__*/React.createElement("h1", {
    className: "title"
  }, "Hello there");
}
En este ejemplo, { className: "title" } es el objeto props, y "Hello there" es el contenido hijo.

Los documentos de React describen la estructura así:

1
React.createElement(type, props, ...children)
El tercer argumento (...children)
El tercer y último argumento son los hijos del elemento - este es el contenido interno que irá dentro del elemento envolvente. Esto es lo que hace posible anidar elementos dentro de otros elementos, de forma similar a como funciona HTML.

Una forma diferente de escribir un condicional if...else
Probablemente estés familiarizado con la estructura de un condicional if...else. Aquí tienes un rápido repaso:

7
let name = 'Bob';
if (name == 'Bob') {
    console.log('Hello, Bob');
} else {
    console.log('Hello, Friend');
};

El código anterior funciona de la siguiente manera:

Primero, declaro una variable name y la establezco en una cadena de "Bob".

A continuación, utilizo la sentencia if para comprobar si el valor de la variable de nombre es "Bob". Si lo es, quiero console.log la palabra "Bob".

De lo contrario, si el valor de la variable de nombre no es "Bob", el bloque else se ejecutará y mostrará las palabras "Hello, Friend" en la consola.

Más arriba te he dado un ejemplo de uso de una condicional if...else. ¿Sabías que hay otra forma diferente de hacer lo mismo? Se conoce como operador ternario. Un operador ternario en JavaScript utiliza dos caracteres distintos: el primero es el signo de interrogación, es decir, el carácter ?. A la izquierda del carácter ?, pones una condición que te gustaría comprobar. Al igual que hice en la sentencia if...else, la condición que estoy comprobando es name == 'Bob'. En otras palabras, le estoy pidiendo al motor de JavaScript que mire el valor que está almacenado dentro de la variable name, y que verifique si ese valor es el mismo que 'Bob'. Si lo es, entonces el motor JavaScript devolverá el valor booleano de true. Si el valor de la variable name es algo diferente de 'Bob', el valor que devolverá el motor JavaScript será el valor booleano de false. 

A continuación se muestra el código que refleja la explicación del párrafo anterior:

1
name == 'Bob' ?
Nótese que el código anterior está incompleto. Tengo la condición que estoy comprobando (la parte name == 'Bob' ). También tengo el carácter ?, es decir, el primero de los dos caracteres necesarios para construir un operador ternario sintácticamente válido. Sin embargo, aún necesito el segundo carácter, que son los dos puntos, es decir, el carácter :. Este carácter se coloca después del signo de interrogación. Ahora puedo ampliar mi código para incluirlo también:

1
name == 'Bob' ? :
Esto me acerca un paso más a completar mi operador ternario. Aunque he añadido los caracteres necesarios para construir el operador ternario, todavía tengo que añadir los valores de retorno. En otras palabras, si name == 'Bob' se evalúa como verdadero, quiero devolver las palabras "¡Sí, es Bob!". En caso contrario, quiero devolver las palabras "No conozco a esta persona".

1
name == 'Bob' ? "Yes, it is Bob" : "I don't know this person";
Una expresión ternaria es una forma abreviada de elegir entre dos valores: un valor si una condición es verdadera, y otro valor si la condición es falsa.

En esencia, así es como funciona el operador ternario. Es sólo una sintaxis abreviada que puedo utilizar como sustituto de la sentencia if. Para probar que este es realmente el caso, aquí está mi ejemplo inicial if...else, escrito como un operador ternario:

3
let name = 'Bob';
name == 'Bob' ? console.log('Hello, Bob') : console.log('Hello, Friend');

Uso de expresiones ternarias en JSX
Examinemos un ejemplo de componente que utiliza una expresión ternaria para cambiar aleatoriamente el texto que se muestra.

1234567
function Example() {
    return (
        <div className="heading">
            <h1>{Math.random() >= 0.5 ? "Over 0.5" : "Under 0.5"}</h1>
        </div>
    );
};
Dentro del elemento <h1>, las llaves indican a React que quieres que analice el código como JavaScript normal.

Luego, dentro de las llaves, puedes añadir una expresión ternaria. Cada declaración ternaria conceptualmente, expresada en pseudo-código, funciona así:

1
condition ? expressionIfTrue : expressionIfFalse
En el ejemplo de código al principio de esta lección, la parte de comparación, que va a la izquierda del signo de interrogación, utiliza el operador >= (mayor que o igual a) para devolver un valor booleano. Si el resultado de la comparación es true, se devuelve la cadena "Más de 0,5". En otras palabras, lo que se encuentre entre el signo de interrogación y los dos puntos se devolverá cuando la condición sea verdadera. En caso contrario, si el resultado de la comparación es false, se devuelve la cadena "Menos de 0,5". En otras palabras, si la comparación es falsa, se devuelve la expresión situada a la derecha de los dos puntos.  

Así es como se puede utilizar una expresión ternaria para comprobar una condición dentro de un componente y devolver un valor dinámicamente.

Uso de llamadas a funciones en JSX
Otra forma de trabajar con una expresión en JSX es invocar una función. La invocación a una función es una expresión porque toda expresión devuelve un valor, y la invocación a una función siempre devolverá un valor, incluso cuando ese valor de retorno sea undefined.

Como en el ejemplo anterior, puedes utilizar la invocación de funciones dentro de JSX para devolver un número aleatorio:

123456789
function Example2() {
    return (
        <div className="heading">
            <h1>Here's a random number from 1 to 10: 
                { Math.floor(Math.random() * 10) + 1 }
            </h1>
        </div>
    );
};
En el componente Example2, se están utilizando los métodos incorporados Math.floor() y Math.random(), así como algunos valores numéricos y operadores aritméticos, para mostrar un número aleatorio entre 1 y 10.

También puede extraer esta funcionalidad en una función independiente:

12345678910
function Example3() {

    const getRandomNum = () => Math.floor(Math.random() * 10) + 1

    return (
        <div className="heading">
            <h1>Here's a random number from 1 to 10: { getRandomNum() }</h1>
        </div>
    );
};
La función getRandomNum() también se puede escribir como una declaración de función, o como una expresión de función. No tiene por qué ser una función de flecha.

Pero observemos ambas alternativas: la expresión de función y la declaración de función.

Expresión de función:

123
const getRandomNum = function() {
    return Math.floor(Math.random() * 10) + 1
} ;
Declaración de función:

123
function getRandomNum() {
    return Math.floor(Math.random() *10) + 1
};
