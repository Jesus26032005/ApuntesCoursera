​En este vídeo, analizaremos los dos tipos siguientes de modelos de regresión, la regresión simple ​y la regresión múltiple. ​La regresión simple se produce cuando una única variable independiente estima una variable dependiente. ​La regresión simple puede ser lineal o no lineal. ​Por ejemplo, predecir la emisión de CO2 utilizando la variable tamaño del motor. ​La regresión lineal simple impone una relación lineal entre las variables dependiente e independiente ​De forma similar, la regresión no lineal crea una relación no lineal entre dichas variables. ​Cuando hay más de una variable independiente, el proceso se denomina regresión múltiple. ​Las distinciones entre relaciones lineales y no lineales se aplican a la ​regresión simple y múltiple.

​Bienvenido a este vídeo sobre la introducción a la regresión lineal simple. ​Después de ver este vídeo, podrá describir la regresión lineal simple y ​explicar cómo funciona la regresión lineal simple. La ​regresión lineal modela una relación lineal entre una variable objetivo continua y las características ​explicativas. ​Considera este conjunto de datos relacionado con las emisiones de CO2 de diferentes automóviles. ​El conjunto de datos presenta el tamaño del motor, la cantidad de cilindros, el consumo de combustible y las emisiones ​de CO2 de varios automóviles. ​Dado este conjunto de datos, la regresión lineal se puede utilizar para predecir un valor continuo, ​como las emisiones de CO2 de un automóvil. ​En la regresión lineal simple, una sola variable independiente estima la variable dependiente. 
​Por ejemplo, en nuestro conjunto de datos, las emisiones de CO2 se predicen utilizando la variable de tamaño del motor. ​Volvamos a considerar el mismo conjunto de datos. ​Vamos a trazar el tamaño del motor como una variable independiente y las emisiones de CO2 como el valor objetivo ​que queremos predecir. ​Un diagrama de dispersión muestra claramente la correlación entre variables en las que los cambios en una variable ​explican o posiblemente provocan cambios en la otra variable. ​Con la regresión lineal simple, puede determinar la línea que mejor se ajuste a través de los datos. ​A medida que aumenta el tamaño del motor, también aumentan las emisiones de CO2, y la relación es aproximadamente lineal. ​Puede usar la regresión lineal simple para predecir la emisión de un automóvil desconocido. 
​Por ejemplo, la emisión prevista para una muestra de automóvil con un tamaño de motor de 2.4 es 201.65. ​Puede predecir el valor objetivo, las emisiones de CO2, representado como la variable de respuesta, y-hat. ​La variable independiente, que en este caso es el tamaño del motor, está representada por la ​variable predictora única, x1. ​El Modelo se representa como la ecuación de una recta, aquí. ​y-hat es la respuesta pronosticada expresada en términos de x1 usando una intersección en y, theta ​cero, y una pendiente, theta uno. ​Theta cero y theta uno se denominan coeficientes del modelo de regresión lineal, seleccionados por el ​algoritmo de regresión lineal para determinar la línea que mejor se ajusta. ​Consideremos algunos puntos de datos nuevos y comprobemos qué tan bien se alinean con la línea de regresión. ​Dado que un automóvil con un tamaño de motor x1 equivale a 5,4, su emisión real de CO2 es de 50, mientras que su ​emisión prevista es y, por lo tanto, igual a 340. 
​Al comparar el valor real con el previsto, hay una discrepancia de 90 unidades. ​El error residual es la distancia vertical desde el punto de datos hasta la ​línea de regresión ajustada. ​El promedio de todos los errores residuales mide qué tan mal se ajusta la línea de regresión a los datos. ​Matemáticamente, podría mostrarse mediante la ecuación, error cuadrático medio, que se muestra como MSE. La ​regresión lineal tiene como objetivo encontrar la línea para minimizar la media de todos estos ​errores residuales. ​Esta forma de regresión se conoce comúnmente como regresión de mínimos cuadrados ordinarios o ​regresión OLS. ​Podemos usar dos fórmulas para calcular los coeficientes theta cero y theta uno del modelo de regresión lineal. 
​La solución fue obtenida de forma independiente por los matemáticos Gauss y Legendre a principios del siglo XIX. ​Requiere que calculemos las medias, barra y y barra x, de las variables independientes y dependientes. ​Los valores xi e yi de la ecuación de theta one se refieren a los valores ith de x e y. ​Aquí, puede calcular la barra x como 3,0 y la barra y como 226,2. ​Luego, haciendo los cálculos, encontrarás que theta 1 es igual a 39. ​Puede usar este resultado para calcular la intersección de línea del primer parámetro como 125,7. ​Por lo tanto, estos son los dos parámetros de la línea, donde theta cero también se denomina coeficiente de sesgo ​y theta uno es el coeficiente de la columna de emisión de CO2. 
​Dados los parámetros de la ecuación lineal, hacer una predicción es tan sencillo como resolver ​la ecuación para un valor de entrada determinado. ​Por ejemplo, puede predecir la emisión de CO2 del tamaño del motor del automóvil en el registro ​número 9 mediante la siguiente ecuación.
