​Bienvenido a este vídeo sobre la clasificación. ​Después de ver este video, podrá: ​describir el método de clasificación del aprendizaje supervisado, analizar las aplicaciones y los casos de uso de la clasificación, ​enumerar los diferentes algoritmos de clasificación y explicar cómo hacer predicciones de varias clases. ​La clasificación es un método de aprendizaje automático supervisado, o ML, ​que utiliza modelos completamente entrenados para predecir las etiquetas de los datos nuevos. ​Las etiquetas de la clasificación forman una variable categórica con valores discretos. ​El aprendizaje supervisado tiene como objetivo comprender los datos en el contexto correcto al responder a una pregunta específica. ​Esto garantiza la precisión de los datos al hacer predicciones. ​A medida que se introducen datos en el modelo, el modelo ajusta los datos para que se ajusten al algoritmo ​y los clasifica en consecuencia, definiendo la entrada y la salida prevista. 
​La clasificación tiene varias aplicaciones en una amplia variedad de industrias. ​Muchos problemas se pueden expresar como asociaciones entre variables de características y de destino, ​especialmente cuando hay datos etiquetados disponibles. ​La clasificación se puede utilizar para crear aplicaciones para el filtrado de correo electrónico, la conversión de voz a texto, el ​reconocimiento de escritura a mano, la identificación biométrica, la clasificación de documentos y mucho más. ​La predicción de abandono se produce cuando se utiliza la clasificación de aprendizaje automático para predecir si un cliente ​interrumpirá un servicio. ​La segmentación de clientes consiste en utilizar la clasificación para predecir la categoría a la que pertenece un cliente. ​También puedes usar la clasificación para predecir si es probable que un cliente responda a una campaña publicitaria. ​Exploremos otros casos de uso de clasificación. 
​Supongamos que a un banco le preocupa que algunos de sus solicitantes de préstamos no puedan reembolsar su préstamo. ​El banco utiliza los datos históricos de incumplimiento de los préstamos para predecir qué clientes tienen probabilidades de incumplir. ​En este caso, se puede entrenar a un clasificador para que utilice la información de los clientes, como la edad, los ingresos y los niveles de deuda crediticia, ​para saber si van a dejar de pagar. ​Dado un cliente nuevo y la misma información, ​pero sin el conocimiento de la probabilidad de incumplimiento, ​el modelo de clasificación entrenado predice si es probable que el cliente incurra en incumplimiento. ​Este es un ejemplo de clasificador binario, ya que sus predicciones se limitan a dos clases posibles. ​Ahora, consideremos el siguiente ejemplo de un clasificador multiclase utilizado para ayudar a recetar varios medicamentos. ​Imagine que ha recopilado datos sobre un conjunto de pacientes, todos los cuales padecían la misma enfermedad. 
​Durante el curso del tratamiento, cada paciente respondió positivamente a uno de los tres medicamentos. ​Puede usar este conjunto de datos etiquetado con un algoritmo de clasificación para crear un modelo de clasificación ​que pueda predecir qué medicamento podría ser apropiado para un futuro paciente con la misma enfermedad. ​Puede usar muchos tipos diferentes de algoritmos para crear su modelo de clasificación. ​Algunos algoritmos de clasificación de aprendizaje automático comunes incluyen Naive Bayes, Logistic Regression, ​Decision Trees, K-Nearest Neighbors, Support Vector Machines y Neural Networks. ​Los algoritmos como la regresión logística, KNN y los árboles de decisión pueden aprender a distinguir varias clases. ​Muchos algoritmos de clasificación no pueden hacer distinciones entre más de dos clases, ​pero puede utilizarlos como componentes para clasificadores de varias clases. ​Las estrategias para extender los clasificadores binarios para que manejen múltiples clases ​incluyen la clasificación de uno contra todos y la clasificación de uno contra uno. 
​El esquema de uno contra todos implementa un conjunto de clasificadores binarios independientes, ​uno para cada etiqueta de clase del conjunto de datos. A ​cada clasificador se le asigna una única etiqueta que define su clase objetivo. ​La tarea de cada clasificador es hacer una predicción binaria para cada punto de datos sobre si ​tiene la etiqueta dada, un clasificador de uno contra el resto. ​Como puede ver, si hay k clases, contribuirán exactamente k clasificadores binarios. ​Comprendamos cómo la estrategia de uno contra todos descompone un conjunto de puntos de datos. ​El algoritmo funciona en cada etiqueta de clase, una a la vez, ​con un resultado entrenado que muestra los puntos que se prevé que tengan un color determinado. ​Tenga en cuenta también que es posible que un punto de datos determinado no pertenezca a ninguna de las clases, ​ya que es posible que ninguno de los clasificadores individuales lo recoja. 
​Estos puntos no clasificados pertenecen a otra clase. ​Esta propiedad puede resultar útil para identificar valores atípicos o ruidos. ​Con la estrategia uno contra uno, en lugar de que cada clasificador decida si un punto pertenece a una clase, ​la pregunta cambia de «¿Es esto?» a «¿Es esto o aquello?» ​Dado un conjunto de clases, considere todos los pares de clases posibles. ​Para cada par de etiquetas, se entrena un clasificador en el subconjunto de datos correspondiente a ​las dos etiquetas y decide a qué clase pertenece cada punto. ​El proceso continúa hasta que todos los clasificadores estén entrenados. 
​La etiqueta de clase final asignada a cada punto puede decidirse mediante un sistema de votación. ​El esquema más simple es por popularidad, ​lo que significa que gana la clase pronosticada por el mayor número de clasificadores binarios. ​Aquí, el verde es el ganador. ​¿Y si hay empate? ​Aquí tenemos tres clases con el mismo número de votos. ​En un escenario en el que eso sea posible, sería mejor utilizar un esquema mejorado, ​sopesando cada voto según el nivel de confianza o la probabilidad asignados a esa clase para cada clasificador. ​Alternativamente, puede intentar usar la clasificación de uno contra todos.
